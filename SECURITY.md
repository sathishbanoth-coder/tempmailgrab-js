# Security Policy

Please report SDK or webhook-verification vulnerabilities privately to
security@tempmailgrab.com. Do not include API keys, inbox contents, or personal
data in a public issue.

Supported releases receive security fixes on the latest major version. For
service-level issues, see https://tempmailgrab.com/security and the published
security.txt at https://tempmailgrab.com/.well-known/security.txt.
